# Take 2 sources: Bell telephone, hand press, switchboard

Researched 2026-11-22. Allowed licences: public domain / CC0 / CC BY (any version) / MIT. NC, ND rejected; BY-SA, GPL, store licences logged as "not on allowed list".
Licences were checked on the source's own page or API (Sketchfab API `/v3/models/<uid>`, Wellcome catalogue API, Met collection API, Internet Archive item metadata, Wikimedia Commons file page for photographers' own uploads).
Downloads live under `tools/sources/take2/<object>/<slug>/` (git-ignored, confirmed with `git check-ignore`). Pixel sizes were measured locally with Pillow (`python -I`, script kept outside the download folders).

**Access problems on this run (not licence problems):**
- **Wikimedia `upload.wikimedia.org`** returned HTTP 429 for every original file and thumbnail ("Too many requests… retry-after 600"). This was an IP-level block, so none of the Commons files are downloaded. Their licences were read from the Commons API (`extmetadata`) for the file page. Download them by hand from the file pages listed.
- **Smithsonian** (si.edu, 3d.si.edu) and the **Library of Congress** (loc.gov) served bot-check pages (403 / "request verification"). The Smithsonian Open Access API (api.data.gov DEMO_KEY) worked until it hit its rate limit.
- **Met images** (`images.metmuseum.org`) served a bot-check page instead of the JPEG. The licence was read from the Met collection API.
- **Sketchfab** downloads need a login, and the archive sizes are hidden without auth (the `archives` field comes back empty), so the size column says "unknown".

## 1. Bell's 1877 telephone (box / butterstamp era)

**3D: nothing good and free exists.** There is no CC0 / CC BY 3D model or scan of a real 1876–78 Bell telephone. The only museum scan (Smithsonian) is non-commercial only. The only CC BY Sketchfab hit says in its own description that it was made with AI. Every other "Bell" model is a candlestick or rotary phone, or a model from a paid store. The telephone has to be told with real engravings and photographs (below), not 3D.

- **Ingenium (Canada) "Telephone replica" 1978.0068.001** (replica of Bell's box telephone 1877): "Copyright Ingenium / CC BY-NC-ND", so rejected.
- **The Henry Ford "Alexander Graham Bell Box Telephone, 1877"** (artifact 17545): an original object, but there is no open licence ("© The Henry Ford"), so rejected.
- **Smithsonian NMAH object records** "Bell telephone, patent #186,787" (nmah_703897), "Bell commercial hand telephone, patent #186,787 and 174,465", "Alexander Graham Bell's Large Box Telephone" (nmah_704159): the metadata is CC0, but the Open Access API returns **no CC0 media** for them, so there is no usable image.
- **Prescott, *The Speaking Telephone* (1878/1879), IA `speakingtelepho01presgoog` / `02presgoog`**: Google bitonal scans with the illustrations blanked out, so useless.
- **Graz Museum "Telephone receiver (AT-GM, STA-01368)"** (Sketchfab, CC BY): a real scan, but a broken fragment of an undated metal receiver, not Bell-era. Not useful.
- **Bell System 1877.jpg** (Commons): CC BY-SA 3.0, not on the allowed list.

## Summary
- **Telephone:** no free 3D exists (Smithsonian scan is NC; Sketchfab hit is AI). Top pick: Du Moncel 1879 Fig. 16, a sectional engraving of the box telephone (PD, downloaded). Best photo: Daderot NMAH "big box telephone" (CC0, 4320 × 3240), still to download by hand.
- **Press:** 3D top pick is arboo's "Columbian Press No 3180" (CC BY, 232k faces, 26 materials / 7 animations, needs login). Alternative: "Albion No. 6551" (William Morris's press; matching CC0 photo by Jim Kuhn). Picture top pick: Wellcome Columbian press lithograph 1852 (PDM, 2244 × 3400, downloaded).
- **Switchboard:** 3D top pick is cimec's Artec scan of an early-1900s cord switchboard (CC BY, 1.19M faces, single mesh, needs login). Picture top pick: Kempster Miller 1905 Paris switchboard plates (PD, 2913 × 4739, downloaded). Photo: Antti Leppänen's Elisa Museum L.M. Ericsson board (CC BY 4.0).
