# Take 2 sources: pin-tumbler lock and gear train

Researched 2026-11-22. I checked every licence on the source page of record: the Sketchfab API (`api.sketchfab.com/v3/models/<uid>`), the Printables GraphQL API (`api.printables.com/graphql/`, the same data as the model page), the Internet Archive item metadata and the Wikimedia Commons file page. I accepted PD, CC0, CC BY and MIT only.

**Download status:** I downloaded only the public-domain Encyclopédie horology plates. Every 3D candidate below needs a manual download:
- **Sketchfab:** downloads need a login. The anonymous API also doesn't return archive sizes, so the download size is unknown unless the author states it.
- **Printables:** the anonymous download-link API answered `files_cannot_be_downloaded`. I didn't try to work around this. Download from the model page in a browser, logged in if Printables asks.

**Polycounts:**
- **Sketchfab:** `faceCount`/`vertexCount` from the Sketchfab API.
- **Printables:** computed from the listed file sizes. Every listed STL is a binary STL (sizes are all 84 + 50·n bytes), so triangles = (bytes − 84) / 50. These are exact for the files as listed. I haven't opened them.

## 1. Pin-tumbler lock (Yale lineage), separable

There is no free, commercially-licensed model of a real, production pin-tumbler cylinder with cam, springs and pins all as separate meshes. What does exist is excellent, accurate pin-tumbler *cutaway trainers*. Locksport hobbyists modelled them in CAD and built working locks from them, one STL per part. They are mechanically true: plug and housing at the shear line, key pins of different lengths, standard and security driver pins, a retaining clip and bitted keys. They are oversized trainers, not a brass Yale. Two gaps in all of them:
- **No springs as meshes.** These designs use bought springs. Only the Sketchfab "3December" lock has visible springs.
- **No tailpiece/cam.** Only ABlueMiata's model has an "Arm".
