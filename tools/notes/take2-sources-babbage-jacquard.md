# Take 2 sources: Babbage's Difference Engine, Jacquard cards and loom head

Researched 2026-11-22. I accepted PD, CC0, CC BY (any version) and MIT only. I checked every licence on the page of record:
- **Wikimedia Commons:** the file page, plus its Flickr-review stamp for Flickr imports.
- **Internet Archive:** item metadata.
- **Wellcome Collection:** catalogue API `api.wellcomecollection.org/catalogue/v2/works/<id>`, the same data as the work page.
- **The Met:** collection API `isPublicDomain`.
- **Sketchfab:** API `api.sketchfab.com/v3/models/<uid>`.
- **Printables:** GraphQL API.
- **Smithsonian:** Open Access metadata dump (S3 `smithsonian-open-access`, the API's own data).
- **Science Museum Group:** the object page.

**Downloads:** files went into `tools/sources/take2/<object>/<slug>/` (git-ignored by `tools/sources/`). Pixel sizes were read with Pillow from a script outside those folders. Sizes are bytes on disk.

**Blocked sites:**
- si.edu, collections.si.edu and americanhistory.si.edu return a bot-verification 403. The `api.si.edu` DEMO_KEY was rate-limited, so I used the Open Access S3 metadata dump instead.
- Thingiverse returns a Cloudflare challenge and its API returns 403.
- DigitaltMuseum returns 403.
- Met image hosting (Incapsula) returns 403.

## Bottom line
- **No free 3D model exists for either object.** No faithful, separable, commercially-licensed model of a difference engine (any of them) or of a Jacquard head or card chain turned up on Sketchfab, Printables, Thingiverse, GitHub, Smithsonian 3D or Science Museum Sketchfab. Every difference-engine model on Sketchfab is all-rights-reserved and not downloadable, and the only printable ones are NC or NC-ND. Details under *Rejected*. **We don't have a 3D object for these two; don't draw one in code.**
- **Real photos and plates are excellent and free.** Picks are below.

## Rejected / seen

### 3D
- **Sketchfab, every difference engine:** "Babbage Difference Engine" (iabma, cb2b2bdc…, 38k faces), "Difference_Engine_Animated" (abdelrahmanwalid, 25d465f7…, 88k faces), "Difference Engine Assembled" (jc342, 6c9ab14c…), and 3dindustries' part set ("Figure wheel / Sector wheel / Restore arm for Difference Engine", parts of thingiverse:7609). The API gives no licence for any of them and they're not downloadable (all rights reserved). Rejected.
- **"Jacquard Loom"** (wboony, 813f886e…, 150k faces) and **"Jaquardloom2"** (demondawson, 4c767cc3…, 137k faces, "captured at the Museum of Technology Berlin 2016", a real scan!): no licence, not downloadable. Rejected. Asking the author for a CC BY release could be worthwhile, but it isn't usable as is.
- **"Métier à tisser Jacquard"** (farhi.abdel, 22ddec1d…, 542k faces): Sketchfab "Standard" store licence. Not on the allowed list.
- **"Punch Card"** (wboony, 20 faces): no licence, and trivial anyway.
- **"Part 1/2 of break, Tattersall & Holdsworth loom"** and **"Mule jenny"** (tine): CC BY-SA, and not Jacquard. Not on the allowed list.
- **Thingiverse thing:7609**, Difference Engine (qwertyzzz18, 2011, printable parts). Thingiverse blocks automated access, so the licence is unverifiable. Not logged as a candidate. If wanted, check it in a browser; 2011 Thingiverse uploads were mostly CC BY-SA or GPL.
- **Difference Engine 0.5** (Michael Freeman, York; OpenSCAD source, simplecpudesign.com): CC BY-NC-ND 4.0. Rejected.
- **"Charles Babbage's Difference Engine: TrialPiece [Work In Process]"** (MechRedPanda, Printables 660789): CC BY-NC. Rejected.
- **Sketchfab, adjacent but out of scope:** "Babbage's Analytical Engine" (paolo.mercoglia, 6eac3324…, CC BY, downloadable, 338k faces, a "non-working reconstruction … made in Maya") and "THE BABBAGE ANALYTICAL ENGINE" (Binkley-Piratepants, 2c90b9ee…, CC BY, 1.38M faces). Licence-clean, but they're the Analytical Engine and an artist's reconstruction, not a scan. Noted only.
- **GitHub:** only code simulators (for example wixette/jacquard-loom-simulator, Apache-2.0). They draw in code, which the project rule excludes.
